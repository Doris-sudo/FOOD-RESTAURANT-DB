# Deploying to Render — Step-by-Step Guide

Your code is already pushed to GitHub at:
https://github.com/Doris-sudo/FOOD-RESTAURANT-DB

Follow these steps exactly. Total time: ~10 minutes.

---

## Step 1 — Create a Render account

Go to https://render.com and sign up (free).
Connect your GitHub account when prompted.

---

## Step 2 — Deploy using the Blueprint (easiest way)

1. In the Render dashboard, click **New +** → **Blueprint**
2. Search for or select your repo: `Doris-sudo/FOOD-RESTAURANT-DB`
3. Render reads the `render.yaml` file automatically and shows you
   three services it will create:
   - `restaurant-db` — PostgreSQL database
   - `maison-laurel-api` — Express backend
   - `maison-laurel-frontend` — Next.js frontend
4. Click **Apply** — Render starts building both services.

> The first build takes 3–5 minutes. Free tier cold starts can be slow.

---

## Step 3 — Get your backend URL

1. Once `maison-laurel-api` shows **Live**, click on it.
2. Copy the URL at the top — it looks like:
   `https://maison-laurel-api.onrender.com`

---

## Step 4 — Set the two environment variables

These can't be set automatically because the URLs aren't known until after deploy.

### On the BACKEND service (`maison-laurel-api`):

1. Go to **Environment** tab
2. Add or update:
   ```
   CORS_ORIGIN = https://maison-laurel-frontend.onrender.com
   ```
   (replace with your actual frontend URL)
3. Click **Save Changes** — the service restarts automatically.

### On the FRONTEND service (`maison-laurel-frontend`):

1. Go to **Environment** tab
2. Add:
   ```
   NEXT_PUBLIC_API_URL = https://maison-laurel-api.onrender.com/api
   ```
   (replace with your actual backend URL)
3. Click **Save Changes** — triggers a rebuild.

---

## Step 5 — Seed the database

The database is empty after first deploy. Run the seed script once:

1. Go to `maison-laurel-api` in the Render dashboard
2. Click the **Shell** tab (top right of the service page)
3. Run:
   ```bash
   node scripts/initDb.js
   ```
4. You should see:
   ```
   ✅  Schema applied.
   ✅  Seed data inserted.
   🎉  Database initialised successfully.
   ```

---

## Step 6 — Open your live site

Go to the URL of `maison-laurel-frontend`:
```
https://maison-laurel-frontend.onrender.com
```

Your restaurant management system is live. 🎉

## Troubleshooting

### Frontend shows "Failed to load menu"
- Check that `NEXT_PUBLIC_API_URL` is set correctly on the frontend service.
- After setting it, click **Manual Deploy → Deploy latest commit** to trigger a rebuild.

### Backend shows "Database connection error"
- Wait 2–3 minutes after first deploy — Render's free PostgreSQL takes a moment to start.
- Check the `DATABASE_URL` environment variable is present on the backend (Render sets this automatically from `render.yaml`).

### CORS errors in browser console
- Check `CORS_ORIGIN` on the backend includes your exact frontend URL (no trailing slash).

### Slow first load
- Render free tier spins down after 15 minutes of inactivity. The first request after sleep takes ~30 seconds. This is normal on the free plan.

## Local → Production environment variable reference

| Variable | Local value | Production value |
|----------|------------|-----------------|
| `DB_*` vars | Your local Postgres | Not needed (replaced by `DATABASE_URL`) |
| `DATABASE_URL` | Not set | Auto-set by Render from `render.yaml` |
| `JWT_SECRET` | Value in `backend/.env` | Auto-generated by Render |
| `CORS_ORIGIN` | `http://localhost:3000` | Your frontend's Render URL |
| `NEXT_PUBLIC_API_URL` | `http://localhost:5000/api` | Your backend's Render URL + `/api` |
